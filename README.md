# 出版 AI × OPC：个人产品规划与交互式原型

面向出版产品负责人的方案作品，探索由一人主导、AI 辅助的产品协作方式。不是已上线的完整出版平台，也不代表已成立公司、已完成试点或已产生营收。

[在线体验：出版 AI × OPC 规划原型](https://wittlud7.github.io/publishing-ai-opc-concept/)

## 作品展示

- 12 个章节覆盖业务问题、产品定位、数据资产、出版流程、人工审核点、90 天试点、阶段决策、商业模式与情景测算。
- AI 阶段切换、三种情景和十项参数支持交互。
- BI / Agent 已交付作品：[在线体验](https://wittlud7.github.io/ecommerce-bi-agent-demo/)。

## 公开范围

原 HTML 保留在本地。本目录为公开方案版：内部请批语气改成个人产品规划，财务参数全部独立重设并使用“演示单位”，不披露企业预算或经营结果。页面没有后台服务、账号、模型接口、用户数据采集或分析追踪。外部链接仅在访问者点击后打开。

测算使用产品数量、成功率、单品贡献、直接成本、平台投入与服务假设进行推演；效率价值与经营净贡献分开展示，不作为可确认利润或现金流。本页不计算贴现、不处理税费和回款时点，也没有用历史经营数据校准。

## 本地与托管

纯静态 HTML，GitHub Pages 设置为 `Deploy from a branch`、`main`、`/(root)` 即可。

## 简历定位

建议名称：**出版行业 AI 产品规划与 OPC 协作原型（个人方案）**。

可表述：围绕出版产品负责人从选题到经营复盘的协作需求，规划数据口径、AI 介入与人工复核节点，设计 90 天验证路径、阶段决策框架及可交互情景测算原型。

不得表述为已经上线的 AI 出版平台、已验证的营收增长、已成立的一人公司或已完成的自动出版系统。
